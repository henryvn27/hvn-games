# Comet

Comet is a short arcade game about steering a growing trail through a small star map. Grab the green beacons, avoid the red rocks and your own tail, and see how long you can keep the route clean.

## Source inspiration and license

The core grow-and-survive loop was selected from [adrianov/snake](https://github.com/adrianov/snake), which is released under the MIT License. HVN Games uses a new Phaser implementation, new visuals, new copy, and a different game shell rather than copying the source code or interface. The upstream copyright notice is retained here because the adaptation is based on that open-source game idea.

## Controls

- Arrow keys or WASD: steer
- Space or P: pause and resume
- On touch screens: use the four direction buttons

## Design read

Comet is a compact arcade route, not a sci-fi dashboard: a dark paper map, visible grid, flat colored pieces, and a tail that becomes the level. Variance 6, motion 5, density 3.

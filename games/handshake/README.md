# Handshake

Four market regulars, five hands each. Choose Share or Keep, read what each player does, and try to win more tables or finish with the higher total.

Both Share: 3 each. One Keeps while the other Shares: 6 and 0. Both Keep: 1 each. Twenty hands make one run; Share and Keep buttons also have S and K keys. P pauses.

Source study: [The Evolution of Trust](https://github.com/ncase/trust), Nicky Case. CC0 1.0. Only its repeated-choice tournament idea informed this original code, art, rules, and copy; no source assets or UI are used.

Install with `npm ci`, run `npm run dev`, and open `/hvn-games/?game=shelf&play=handshake`. See DESIGN.md and INTEGRATION.md for details.

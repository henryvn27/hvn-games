# Spookyball

Native HVN 2D paddle-and-ball arcade game. Move with ← → or A/D; clear the brick wall, keep lives, and save a score after the round.

Reference study: [toji/spookyball](https://github.com/toji/spookyball), MIT, 144 GitHub stars checked 2026-09-24. Only the broad Breakout-style play loop informed this game. No upstream code, WebGPU, 3D asset, texture, or model is included.

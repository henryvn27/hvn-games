Privacy

Last updated September 22, 2026

What HVN games stores

Game scores, player names, tutorial state, and small play reports are stored in this browser using local storage. When the shared leaderboard is connected, a submitted score sends only the player-chosen display name, score, game id, game counters, submission id, and server timestamp to the HVN Games Google Apps Script leaderboard, which stores rows in a private Google Sheet. There is no account, precise location, or contact list.

Shared leaderboard

The shared board is optional and displays submitted names and scores publicly, separated by game. The placeholder name “YOU” is treated as unset and is never submitted; a player must choose a name or initials before a score is saved. The project owner can moderate or remove rows in the private leaderboard sheet. To request removal of a score, keep the displayed name and approximate score and contact the repository owner through the public repository; do not include private information in an issue.

Playtime ranking

Playtime sharing is off until you choose “Share playtime.” If you turn it on, HVN games counts seconds while a game page is open in a visible browser tab and sends the game id, seconds, and a random one-time receipt used only to prevent duplicate uploads. It does not send a player name, score, account, or persistent device or browser id. The Google Apps Script stores aggregate totals by game in the private leaderboard spreadsheet; those totals decide which ten games appear on the home page. You can turn sharing off from the playtime controls on any page. That stops future uploads and clears unsent local time. Because stored totals are not tied to a person, an individual contribution cannot be identified or removed after it has been added.

On the hidden-games page, you can ask to put a game on the home page. That sends its game id and a random receipt so the request is counted once per browser and game. The receipt stays in local storage so retries do not add duplicate requests. The newest request can move that game into the shared featured ten and replace the last game there. No name, account, or shared browser id is attached to the request.

Advertising

HVN games loads Google AdSense page-level ads. Google may use cookies, local storage, device information, and usage information to serve and measure ads according to its policies. Google’s consent and privacy messages may ask for an opt-in or offer an opt-out based on your location and applicable privacy rules.

When Google does not fill an ad slot, HVN games may show a Scoutly promotion. It does not add tracking to HVN games. Selecting it takes you to scoutly.one.

Google’s information about partner sites is available at Google partner-site privacy. Ad preferences and consent requirements may vary by location.

Changes and questions

# 2048

HVN's native version of the sliding-tile puzzle: combine matching values, build toward 2048, then keep playing if you want.

The source review started with [gabrielecirulli/2048](https://github.com/gabrielecirulli/2048), an MIT-licensed repository with 13.4k GitHub stars when checked on 2026-09-23. HVN's game logic and interface are a fresh implementation; no upstream source, artwork, or styling is bundled.

Controls: arrow keys or WASD; swipe on touch screens. Undo rolls back one move. Best score is stored locally in this browser.

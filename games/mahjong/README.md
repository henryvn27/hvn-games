# Mahjong Solitaire

Native HVN pair-matching game with a small layered board, open-side rules, hint, reshuffle, timer, and score. Select two matching tiles that are uncovered and open on at least one side.

Reference study: [ffalt/mah](https://github.com/ffalt/mah), MIT, 148 GitHub stars checked 2026-09-24. Tile availability and matching informed the rules; the 40-tile layout and symbols are original. No upstream code, board layout, or art is included.

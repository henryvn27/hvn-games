# Maze Chase

Native HVN maze game. Move with arrow keys or WASD; collect every dot, use the power orbs, and avoid the pursuer. The simulation is tested independently of the canvas runtime.

Reference study: [mumuy/pacman](https://github.com/mumuy/pacman), MIT, about 1.6k GitHub stars checked 2026-09-24. Pellet scoring, power-ups, and pursuit informed the mechanics. No upstream code, map, or art is included.

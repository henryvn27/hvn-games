# Chess

Play a three-minute match against the computer. Win to face a sharper opponent; a loss or draw ends the ladder. Two players can also share one screen.

Tap a piece and its destination. On desktop, arrow keys move the square focus; Enter selects it. Press P or Pause to stop both clocks. Take back is available during play. Castling, en passant, and all four promotion choices are supported.

The computer uses a small local search that deepens as the ladder goes on. A run is ranked by consecutive wins and saved to the Chess board. The best personal run stays in this browser.

The board uses the `chess.js` rules library, version 1.4.0, under BSD-2-Clause. Its license is included in `LICENSE.chess.js.txt`. No upstream UI or artwork is used.

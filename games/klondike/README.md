# Klondike

Native HVN seven-column solitaire deal. Click the stock to draw or recycle; move face-up runs between tableau columns and build each foundation from Ace to King.

Reference study: [gcedo/react-solitaire](https://github.com/gcedo/react-solitaire), MIT, 182 GitHub stars, last pushed 2019-10-28 (metadata checked 2026-09-24). Its playable browser demo and standard Klondike move rules informed the model. The project is an older reference; no upstream code, interface, or card art is included.

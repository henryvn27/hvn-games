# Asteroids

Native canvas arcade game: steer with the arrow keys or touch controls, split rocks with shots, and clear three waves.

Reference study: [dmcinnes/HTML5-Asteroids](https://github.com/dmcinnes/HTML5-Asteroids), MIT, 355 GitHub stars, last pushed 2024-04-19 (metadata checked 2026-09-24). Rules informed a fresh simulation and canvas presentation; no upstream code or assets are included.

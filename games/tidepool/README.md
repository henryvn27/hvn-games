# Tidepool

Shape a small shoreline with sand and rock, then plant kelp where the rising water can reach it. Keep enough mature plants alive through three increasingly quick tides.

Open Tidepool from the HVN Games shelf. Select a material and click or drag on the board; keys 1–4 select the same tools. Press P or Pause to freeze the tide. Clear all three trials to bank the run.

Sand falls until it reaches something solid. Kelp needs a solid cell underneath and nearby water to grow. The starting shore is rock-backed so it stays usable while the tide moves.

Gameplay inspiration: [Sandspiel](https://github.com/MaxBittker/sandspiel), whose repository declares the MIT license. Tidepool uses an original shoreline objective, rules, code, art, and interface; it includes no upstream code or assets.

Open HVN Games and choose Tidepool from the game shelf. Drag across the board to paint. Select Sand, Water, Rock, or Kelp from the controls; keys 1–4 select the same tools. Press P or Pause to freeze the simulation.

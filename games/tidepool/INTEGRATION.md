# Integration contract

Trigger: choose Tidepool from the shared HVN Games shelf. Input: pointer or touch brush strokes and keys 1–4/P. Output: game progress and a score tagged `tidepool`. The shelf and leaderboard are the adoption point. Manual fallback: run the site locally with `npm run dev`. Rollback: remove the Tidepool route and its leaderboard/reward registry entries. Proof: simulation tests, site build, and browser playthrough.

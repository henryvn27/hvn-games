# Invaders

Hold the moon relay. Move along the ridge and fire before the descending ships reach it. Clear each formation to bring in the next, faster wave. Three hits end the run.

Controls: A/D or left/right to move, Space to fire, P or Escape to pause. On touch screens use the three buttons below the playfield.

## Source inspiration

The fixed-screen formation-shooter loop was researched in [susam/invaders](https://github.com/susam/invaders) (MIT, 185 GitHub stars when selected; upstream demo: [susam.net/invaders.html](https://susam.net/invaders.html)). The HVN implementation is written independently for this site and uses no upstream source code or assets.

Design read: a moon-relay defense with a dusty horizon, compact orbital craft, and a readable HUD. The playfield keeps its night-sky palette; controls and scores use ink that contrasts with the light site surface. No cabinet frame or fake telemetry. Touch taps fire or nudge once, holds repeat, and keyboard controls work even when Start has focus. Early waves give players time to react before later waves speed up.

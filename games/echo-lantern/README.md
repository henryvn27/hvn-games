# Echo Lantern

A 45-second pulse-to-reveal navigation run. Move through the dark, send a pulse, and chase each beacon before its echo fades.

## Controls

- Move: WASD or arrow keys
- Pulse: Space, tap, or the in-game Pulse button
- Pause: P
- Restart after a run: R

## Design read

A deep-field observatory with a mint pulse ring, fading colored beacons, and coral orbit hazards. The pulse is both the key verb and the feedback that teaches the route.
